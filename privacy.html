Privacy Policy

Effective: 30 September 2026

ClodVideo Publisher is an experimental desktop application. Its local account manager stores TikTok usernames and account-selection state on the operator's computer. If a user completes TikTok OAuth, the application is designed to store the resulting account identifier and access credentials locally, encrypted for the Windows user. OAuth has not yet been enabled or tested with a live account.

The application requests TikTok creator information to verify which account was authorized. The present prototype has no API publishing function. It does not sell personal data or operate a remote account database. TikTok processes information according to its own privacy policy when users visit TikTok or authorize the application.

An operator can stop using the application and remove its local account database. TikTok access can be revoked through TikTok's account settings. A production release may use different storage or services and would require this policy to be updated first.
